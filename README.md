This is a simple 3d printed marble run, It has a few parts in it, firstly being the entrance tube so each marble can have a equal
competition. After that, the marble are rolled into the curved tube, which reduces the initial speed gained at the beginning and
allows the marble to enter the funnel at a manageable rate. The marbles then fall into the side of the funnel, so they can get the 
most spin time inside the funnel and would allow for some collisions and overtaking to occur. The marbles that make it through 
would then go through the tube below the funnel into the plinko machine, which is the final part and would allow more overtaking to occur 
and be the deciding factor for which marble wins the race. This is how the marble run looks like:
